# Requirements quality checklist

- [x] Requirements identify one normative governance engine.
- [x] Spec Kit pin is explicit; GSD is explicitly disabled (speckit-only) unless re-enabled with pin/entrypoints.
- [x] Repository authorization is distinct from runtime/deploy authority.
- [x] Acceptance criteria are mechanically verifiable.
- [x] No application behavior, production effect or secret is in scope.
