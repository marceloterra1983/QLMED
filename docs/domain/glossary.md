# Domain glossary

| Term | Meaning |
|------|---------|
| NF-e | Electronic product invoice represented by a fiscal XML document. |
| CT-e | Electronic transport document. |
| NFS-e | Electronic service invoice. |
| Access key | Stable fiscal identifier used to identify an NF-e or CT-e. |
| Company | The QLMED business entity that owns operational and fiscal data. |
| Invoice direction | Whether a fiscal document was issued or received by the company. |
| SEFAZ | Brazilian state tax authority integration used for fiscal documents. |
| NSDocs | External fiscal-document provider integrated by QLMED. |
| Product registry | Consolidated product information derived from fiscal documents and user maintenance. |
| Transactional outbox | Durable queue pattern used to publish notifications after database changes. |
