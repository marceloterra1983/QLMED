### Wave 2 — SPEC-006 Eventos DistDFe (inbound)

**Depende de D2.** Default: persistir, não transmitir.

Hoje o client classifica (`tipo`, às vezes `descEvento` vazio) e o sync
**ignora** `doc.tipo`: só `parseInvoiceXml` → `null` → `continue`. Evento
nunca vira Invoice (upsert só após parse). `NotificationOutboxEvent` **não**

2. `resEvento`/`procEventoNFe` → `invoice_event` (`accessKey`, `tpEvento`, `nSeqEvento`, `descEvento`, XML, NSU, `companyId`). Unique `(accessKey, tpEvento, nSeqEvento)`.
3. `nfeProc` → upsert como hoje; promove o pendente.

**Wave 2b (só se D2/ciência pontual):** `recepcaoEvento` 210210 para chaves
com `resNFe` e sem `nfeProc` após N dias. Não automatizar conclusivos.

→ verify: fixture `resNFe` não vira Invoice; fixture `procEventoNFe` grava evento; fixture `nfeProc` continua upsert.

### Wave 3 — SPEC-007 Lote: localização de entradas (não chamar de recall)

Especialista ANVISA: consulta sem baixa **não é recall**. UI e spec devem
dizer “entradas por lote”, nunca “em estoque” nem “recall”.

- Reverso: lote → NF-e de **entrada**, fornecedor, validade, qtd capturada
- Direto: produto/ANVISA → lotes **entrados** (não “abertos”)
- Inferência honesta de saída: cruzar NF-e **emitidas** já capturadas
  (quantidade/SKU; lote de saída só se o XML de venda tiver `nLote`)
- Banner fixo: “sem baixa de estoque — não é saldo físico”
- Excluir `lot IS NULL` da consulta; mostrar **% cobertura de lote** por produto
- `lotSerial` é regex no texto do item, não tag fiscal — rotular “série inferida”
- Relatório Corcym **não** reutiliza isto: hoje agrega XML + `REAL_STOCK`
  hardcoded (`valvulas-importadas/route.ts`). Fica separado até spec própria

**Fora:** WMS, FEFO picking, consignado, bloqueio de vencido no faturamento.
Recall regulatório de válvula é processo humano + esta consulta; o software
não mente.

→ verify: 2 lotes do mesmo SKU listam 2 chaves de entrada; copy da UI não
contém a palavra “recall” nem “saldo”.

## 7. Critério de “estamos no estado da arte do *nosso* job”

Não é Omie. É isto, medido:

- XML 2026 com IBS/CBS projeta e aparece no detalhe; XML sem grupos continua válido
- Evento DistDFe não some
- Lote de **entrada** é localizável; a UI não chama isso de saldo nem recall
- Duplicata tem sidecar Decimal com teste de divergência
- UDI no cadastro é validado e não afirma transmissão SIUD

Enquanto emissão, WMS e Next 16 estiverem fora, **não** declarar estado da
arte do nicho hospitalar — só do backoffice inbound.
