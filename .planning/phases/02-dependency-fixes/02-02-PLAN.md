       **New exceljs pattern:**
       ```typescript

       ```

       Replace the helper functions:
       - `cellStr(ws, r, c)` becomes: `String(worksheet.getCell(r + 1, c + 1).value ?? '').trim()`
         NOTE: exceljs uses 1-based indexing (row 1, col 1), xlsx used 0-based. Add +1 to all row/col references.
       - `cellNum(ws, r, c)` becomes: get cell value, convert to Number, return null if NaN.
       - `XLSX.utils.decode_range(ws['!ref']).e.r` becomes: `worksheet.rowCount` (last row number, 1-based).

       Key differences to handle:
       - exceljs rows/cols are 1-based (xlsx was 0-based)
       - `HEADER_ROW = 2` (0-based) becomes row 3 (1-based) in getCell calls
       - `DATA_START_ROW = 4` (0-based) becomes row 5 (1-based) in getCell calls
       - Loop: `for (let r = DATA_START_ROW; r <= range.e.r; r++)` becomes `for (let r = 5; r <= worksheet.rowCount; r++)` with getCell using 1-based r directly.

       IMPORTANT: Keep the `cellStr` and `cellNum` helper functions but rewrite their internals. This preserves the call sites unchanged (callers still pass 0-based r, c — helpers add +1 internally). This is the safest approach:
       ```typescript
       function cellStr(ws: ExcelJS.Worksheet, r: number, c: number): string {
         const cell = ws.getCell(r + 1, c + 1);
         return cell.value != null ? String(cell.value).trim() : '';
       }
       function cellNum(ws: ExcelJS.Worksheet, r: number, c: number): number | null {
         const cell = ws.getCell(r + 1, c + 1);
         if (cell.value == null) return null;
         const n = Number(cell.value);
         return isNaN(n) ? null : n;
       }
       ```
       Then the rest of the code stays exactly the same (same constants, same loop bounds, same cellStr/cellNum calls). Only the top-level read changes:
       ```typescript
       const workbook = new ExcelJS.Workbook();
       await workbook.xlsx.load(buffer);
       const ws = workbook.worksheets[0];
       if (!ws || ws.rowCount === 0) {
         return NextResponse.json({ error: 'Planilha vazia' }, { status: 400 });
       }
       const lastRow = ws.rowCount - 1; // Convert to 0-based for existing loop
       ```
       And the range check: `range.e.r` becomes `lastRow`.

    3. Rewrite `src/app/api/products/import-types/route.ts`:

       **Current pattern:**
       ```
       const { read, utils } = await import('xlsx');
       ```

       ```typescript

       const workbook = new ExcelJS.Workbook();

       // Convert to row arrays (equivalent to sheet_to_json with header: 1)
       const allRows: string[][] = [];

         // row.values is 1-based (index 0 is undefined), slice from 1
         allRows.push(values.slice(1).map(v => v != null ? String(v) : ''));
       });
       ```
       The rest of the code (header detection, tipo/subtipo parsing) stays the same since it operates on `allRows: string[][]`.
