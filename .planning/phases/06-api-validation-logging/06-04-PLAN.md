  <action>
For each POST/PUT/PATCH handler in the listed routes:

1. Import the appropriate schema from `@/lib/schemas/`
2. Import `apiValidationError` from `@/lib/api-error`
3. At the top of the handler, parse the request body through the schema:

For JSON body routes:
```typescript
const body = await request.json()
const parsed = someSchema.safeParse(body)
if (!parsed.success) return apiValidationError(parsed.error)
// Use parsed.data instead of body from here on
```

For FormData routes (upload, certificate, import-e509):
```typescript
const formData = await request.formData()
const fields = { companyId: formData.get('companyId'), /* etc */ }
const parsed = someFieldsSchema.safeParse(fields)
if (!parsed.success) return apiValidationError(parsed.error)
// File validation stays as-is (check file exists, check extension)
```

For routes with URL params (e.g., [invoiceId]):
```typescript
const paramsParsed = idParamSchema.safeParse({ id: params.invoiceId })
if (!paramsParsed.success) return apiValidationError(paramsParsed.error)
```
