5. **The main breaking change: async request APIs.** In Next.js 15, these are now async and must be awaited:
   - `params` in dynamic routes — `{ params }: { params: { id: string } }` becomes `{ params }: { params: Promise<{ id: string }> }` and requires `const { id } = await params;`
   - `searchParams` in page components — same pattern
   - `cookies()` from `next/headers` — now returns `Promise<ReadonlyRequestCookies>`
   - `headers()` from `next/headers` — now returns `Promise<Headers>`

6. **Fix all dynamic route handlers (15 files):**

   For each file in `src/app/api/*/[id]*/route.ts` and `src/app/api/*/[invoiceId]*/route.ts`:
   - Change function signature: `{ params }: { params: Promise<{ id: string }> }`
   - Add `const { id } = await params;` at the start of handler
   - Remove old destructuring

   Files to update (all identified):
