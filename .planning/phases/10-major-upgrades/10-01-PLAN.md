
3. **Create `eslint.config.mjs`** — Convert current `.eslintrc.json`:
   ```javascript
   import { FlatCompat } from '@eslint/eslintrc';
   import path from 'path';
   import { fileURLToPath } from 'url';

   const __filename = fileURLToPath(import.meta.url);
   const __dirname = path.dirname(__filename);

   const compat = new FlatCompat({
     baseDirectory: __dirname,
   });

   const eslintConfig = [
     ...compat.extends('next/core-web-vitals'),
   ];

   export default eslintConfig;
   ```

   If eslint-config-next natively supports flat config (check docs), use direct import instead of FlatCompat.

4. **Delete `.eslintrc.json`**.

5. **Install `@eslint/eslintrc`** if needed for compat layer:
   ```bash
   npm install --save-dev @eslint/eslintrc
   ```

6. **Run `npm run lint`** and fix any new lint errors introduced by the upgrade. Common issues:

   - Plugin compatibility
   - Config format differences
