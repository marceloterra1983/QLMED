Upgrade each dependency one at a time, fixing breaking changes after each:

**1. bcryptjs 2 -> 3:**
```bash
npm install bcryptjs@3 @types/bcryptjs@latest
```
- Check migration guide. bcryptjs v3 may have minor API changes.
- Grep for all bcryptjs usage: `grep -rn "bcrypt" src/` and verify import/API compatibility.
- Test: password hashing and comparison still works (check auth-options.ts, users route).

**2. zod 3 -> 4:**
```bash
npm install zod@4
```
- Zod 4 has significant API changes. Check the migration guide at https://zod.dev/v4
- Key breaking changes to check:
  - `z.object().strict()` behavior changes
  - `.catch()` method behavior
  - Error formatting changes
  - `z.infer` still works the same way
- Grep for all zod usage: `grep -rn "from 'zod'" src/` — there are many schemas in `src/lib/schemas/` and inline in API routes.
- Fix any compilation errors after upgrade.
- If Zod 4 has too many breaking changes and would require >30 min of fixes, stay on latest Zod 3 patch instead. Document the decision.

**3. typescript 5 -> 6:**
```bash
npm install --save-dev typescript@6
```
- TypeScript 6 may introduce stricter checks. Run `npx tsc --noEmit` and fix any new errors.
- Check tsconfig.json for any deprecated options.

After all upgrades:
```bash
npm run build
```
Fix any build errors.
