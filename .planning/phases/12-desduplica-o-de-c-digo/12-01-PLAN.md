<objective>
Eliminate the divergent duplication between `src/app/api/products/route.ts` and
`src/lib/product-aggregation.ts` (CODEDUP-01 / ARCH-REMEDIATION-PLAN Fase 5.1):
`route.ts` currently reimplements `UNIT_ALIASES`, `normalizeUnit`,
`buildProductKey`, `extractProductsFromXml`, and the `ProductFromXml`
interface inline (lines ~22-250), even though byte-identical exports already
exist in `product-aggregation.ts`. Remove the inline copies, import from the
lib, and prove the API response is unchanged via an automated snapshot test
— this is a pure refactor, zero behavior change.

Purpose: stop the two files from drifting apart silently (the exact failure
mode the architecture review flagged) and shrink `route.ts` toward being a
thin orchestrator.
Output: `route.ts` importing shared helpers from the lib; a vitest snapshot
test (`products-route-dedup.test.ts`) that fails loudly if a future change
alters `/api/products`'s response shape.
</objective>
