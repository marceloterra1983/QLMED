1. **Remove the hardcoded PIN_MAP** (lines 6-14). Replace with a function that lazily parses from env:

```typescript
function getPinMap(): Record<string, string> {
  const raw = process.env.PIN_MAP_JSON;
  if (!raw) return {};
  try {
    return JSON.parse(raw);
  } catch {
    console.error('[Auth] PIN_MAP_JSON env var is not valid JSON');
    return {};
  }
}
```

2. **Update authorize function** to use `getPinMap()`:
   - Replace `const pinEmail = PIN_MAP[credentials.password]` with `const pinEmail = getPinMap()[credentials.password]`
