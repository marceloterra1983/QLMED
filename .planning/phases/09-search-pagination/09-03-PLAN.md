  <action>
1. **Create `src/lib/cache-headers.ts`** with cache profile helpers:
   ```typescript
   export const CACHE_PROFILES = {
     dashboard: 'private, max-age=30',           // Dashboard stats refresh every 30s
     list: 'private, max-age=10',                 // Lists refresh every 10s
     lookup: 'public, max-age=3600',              // NCM, CNPJ lookups cache 1 hour
     detail: 'private, max-age=60',               // Single record details
     none: 'no-store',                             // Mutations, uploads
   } as const;

   type CacheProfile = keyof typeof CACHE_PROFILES;

   export function cacheHeaders(profile: CacheProfile): HeadersInit {
     return { 'Cache-Control': CACHE_PROFILES[profile] };
   }
   ```

2. **Apply to dashboard route** — In the NextResponse.json() call, add headers:
   ```typescript
   return NextResponse.json(data, { headers: cacheHeaders('dashboard') });
   ```

3. **Apply to list routes** — invoices/route.ts and products/list/route.ts:
   ```typescript
   return NextResponse.json(data, { headers: cacheHeaders('list') });
   ```

4. **Apply to lookup routes** — ncm/search/route.ts, contacts/cnpj-status/route.ts:
   ```typescript
   return NextResponse.json(data, { headers: cacheHeaders('lookup') });
   ```

5. **Do NOT add cache headers to mutation routes** (POST/PUT/DELETE) or error responses. Only add to successful GET responses.

Apply to at least 5 representative routes from each category. Other routes can be updated incrementally.
